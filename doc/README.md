# 文档总览

本目录只做入口：列出各份文档的角色与权威边界，不重复正文。文档清单之外的新增说明请先确定归属位置，再写入对应文件。

## 阅读顺序与权威边界

1. `../README.md`：安装、使用、目录导航和手工 TUI 验证。用户可见的现行规格以此为准。
2. `../AGENTS.md`：项目实现约束、数据边界和验证命令。
3. `../src/README.md` / `../extensions/README.md` / `../test/README.md`：代码层职责与入口导航。
4. `decisions/`：不可轻易推翻的决定及其理由（接入哪些字段、拒绝哪些字段）。
5. `references/`：来源、验证材料与历史阶段记录，不是现行权威。
6. `../CHANGELOG.md`：用户可感知变更时间线，不作为当前架构或路线图权威。

当前实现以源代码、测试和对应分层 README 为准；本目录没有路线图、版本实施方案或历史归档文档，因此暂不创建 `00 / 10 / 20 / 30 / 40 / 90` 编号目录。后续出现路线图、版本方案或历史材料时，再分别迁入对应编号段。

## 文档清单

- `../README.md`：安装、使用和手工 TUI 验证。
- `../AGENTS.md`：项目实现约束与验证命令。
- `../CHANGELOG.md`：用户可感知变更。
- `decisions/footer-data-scope.md`：Footer 数据接入范围的决策档案。
- `references/pi-footer-public-data-audit.md`：Pi Footer 公开数据源审查记录（来源与验证材料）。
- `../src/README.md`：核心模块职责。
- `../extensions/README.md`：Pi 扩展入口职责。
- `../test/README.md`：行为测试目录与测试文件导航。

## 正文归属

- 现行组件清单、布局语义、溢出策略与组件绑定规则：见 `../README.md` 的「使用」一节。
- 数据边界与配置契约：见 `../AGENTS.md` 的「项目边界」一节。
- 实现细节与模块职责：见 `../src/README.md` 及源码本身。
